# Combe Down's map data

Everything the Combe Down map (the whole of Bath) is built from, as the build reads it, so it
rebuilds from a fresh clone with no downloads. `python3 -I tools/mapdata.py unpack combe-down`
puts it where the build tools look (`data/raw/combe-down/wide/`), and the squares and the wide file
read `measured/` straight from here. "Rebuild a map" in the top README has the whole build;
`tools/mapdata.py` says how each part is kept, and `tools/fetch.py` how to fetch it all again.

The certificates' addresses are left out on purpose: the EPC registers' address data comes under
Royal Mail and Ordnance Survey copyright terms, not the Open Government Licence the rest is
under. The build only ever compared
the first part of a business's address (usually its name) with the names in OpenStreetMap and
Overture, which it still can, as hashes.

The Overture and OpenStreetMap parts are shared under the Open Database Licence, as the map built
from them is.
